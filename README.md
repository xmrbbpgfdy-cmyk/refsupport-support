# RefSupport Support-Website

Statische, zweisprachige Support- und Rechtstexte für die App RefSupport (Support, Datenschutz, Nutzungsbedingungen, Impressum). Die Website benötigt keinen Build-Schritt, kein JavaScript und keine externen Assets (Screenshots liegen lokal in `images/`) und wird über GitHub Pages ausgeliefert.
